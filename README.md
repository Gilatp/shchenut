# שכנות שלובות

משחק חברתי על הקשרים המפתיעים שבין אנשים. כמה רחוקות אנחנו באמת?

שולפות קלף, מנחשות, מהמרות ומחפשות שרשראות היכרות. כל קלף מותח חוט במפת הקשרים: חוט מלא לקשר שהתגלה, מקווקו לקשר שנוצר הערב.

קובץ אחד (`index.html`), בלי שרת ובלי התקנה. מתאים למסך גדול או לטלפון אחד. האתר מתפרסם דרך GitHub Pages מתוך ענף `main`.
